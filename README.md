## 🇬🇧 English

A robust Python bridge that parses structured task JSON generated by AI LLMs (Gemini, ChatGPT, Claude, etc.) or automation workflows and batch-creates them in Todoist via the official REST API with automatic project mapping, due date assignment, and validation.

### 🌟 Features

- **Pydantic Validation:** Strict type-safe schema verification for individual and batch task creation payloads.
- **Markdown & JSON Extraction:** Automatic cleaning and stripping of markdown code fences (````json ... ````) from raw LLM responses.
- **Smart Project Resolution:** Resolves human-readable `project_name` to Todoist `project_id` via dynamic case-insensitive lookup. Defaults safely to `Inbox` if not matched.
- **Up-to-Date Todoist API v1:** Fully migrated and compliant with the latest Todoist API endpoints (`https://api.todoist.com/api/v1`).
- **Rich Terminal Summary:** Formatted and colored summary table with direct clickable links to created tasks on Todoist web app.
- **Flexible Input Sources:** Supports JSON file paths (`--file`), direct CLI arguments (`--json`), piped streams (`stdin`), or interactive copy-paste.

### 📁 Project Structure

```text
Todoist-Gemini-Bridge/
├── config.py           # Environment variables & Pydantic settings
├── models.py           # TaskPayload & BatchTaskPayload Pydantic schemas
├── parser.py           # JSON cleaner and parser
├── todoist_client.py   # Todoist REST API client with error handling
├── main.py             # CLI runner and interactive table formatter
├── tasks_sample.json   # Sample task template
├── requirements.txt    # Python dependencies
└── .env.example        # Environment variable template
```

### 🚀 Getting Started

#### 1. Clone the Repository
```bash
git clone https://github.com/kagankurubas/Todoist-Gemini-Bridge.git
cd Todoist-Gemini-Bridge
```

#### 2. Setup Virtual Environment & Install Dependencies
```bash
python -m venv venv

# On Windows (PowerShell):
.\venv\Scripts\activate

# On macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
```

#### 3. Configure API Credentials
Copy `.env.example` to `.env` and add your Todoist API token:
```bash
cp .env.example .env
```
Inside `.env`:
```env
TODOIST_API_TOKEN=your_todoist_api_token_here
```
> **Tip:** You can obtain your personal API token from [Todoist Settings > Developer](https://todoist.com/app/settings/integrations/developer).

### 🛠️ Usage

#### Option A: Import from JSON file
```bash
python main.py --file tasks_sample.json
```

#### Option B: Direct CLI JSON Argument
```bash
python main.py --json '[{"content": "Prepare Quarterly Report", "project_name": "Work", "due_string": "tomorrow at 14:00", "priority": 3}]'
```

#### Option C: Interactive / Piped Input
Run without arguments and paste your JSON:
```bash
python main.py
```
*(Paste JSON in the terminal and press `Ctrl+Z` then `Enter` on Windows, or `Ctrl+D` on macOS/Linux).*

## 🇹🇷 Türkçe

Yapay zeka modellerinden (Gemini, ChatGPT, Claude vb.) veya otomasyon araçlarından üretilen yapılandırılmış JSON görev çıktılarını Todoist API'si üzerinden tek seferde, doğru projelere ve tarihlere otomatik eşleyerek ekleyen Python köprüsü.

### 🌟 Özellikler

- **Pydantic ile Şema Doğrulama:** Tekil veya toplu görev verilerinin tiplerini ve şemalarını sıkı bir şekilde doğrular.
- **Markdown & JSON Ayıklama:** LLM çıktılarındaki markdown formatlı kod bloklarını (````json ... ````) otomatik olarak temizler ve ayrıştırır.
- **Akıllı Proje Eşleme:** Görevdeki `project_name` değerini Todoist'teki projelerinizle otomatik eşleştirip `project_id` değerini bulur. Bulunamazsa görevi güvenle `Inbox`'a yönlendirir.
- **Güncel Todoist API v1 Desteği:** En güncel Todoist API (`https://api.todoist.com/api/v1`) uç noktalarıyla tam uyumludur.
- **Renkli Konsol Özeti ve Görev Linkleri:** Eklenen görevlerin doğrudan Todoist web linklerini ve özetini terminalde renkli tablo halinde gösterir.
- **Esnek Giriş Yöntemleri:** JSON dosya yolu (`--file`), doğrudan komut satırı argümanı (`--json`), boru hattı (`stdin`) veya interaktif yapıştırma desteği.
