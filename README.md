## 🇬🇧 English

A robust Python bridge that parses structured task JSON generated by AI LLMs (Gemini, ChatGPT, Claude, etc.) or automation workflows (n8n, Make, Custom Webhooks) and batch-creates them in Todoist via the official REST API with automatic project mapping, due date assignment, and validation.

### 🌟 Features

- **Pydantic Validation:** Strict type-safe schema verification for individual and batch task creation payloads.
- **Markdown & JSON Extraction:** Automatic cleaning and stripping of markdown code fences (````json ... ````) from raw LLM responses.
- **Smart Project Resolution:** Resolves human-readable `project_name` to Todoist `project_id` via dynamic case-insensitive lookup. Defaults safely to `Inbox` if not matched.
- **FastAPI Webhook Server (`app.py`):** Production-ready REST API endpoints with CORS and pre-shared token security (`X-Bridge-Token`).
- **CLI Dispatcher (`send_to_bridge.py`):** Standalone command-line client to transmit task payloads to your self-hosted bridge server.
- **Direct CLI Runner (`main.py`):** Standalone script to create tasks directly in Todoist without running a server.
- **Gemini Tool Declaration (`gemini_tool_schema.json`):** Ready-to-use Google Gemini Function Calling schema.
- **Up-to-Date Todoist API v1:** Fully compliant with the latest Todoist API endpoints (`https://api.todoist.com/api/v1`).
- **Rich Terminal Summary:** Formatted and colored summary table with direct clickable links to created tasks on Todoist web app.

### 🚀 Getting Started

#### 1. Clone the Repository
```bash
git clone https://github.com/kagankurubas/Todoist-Gemini-Bridge.git
cd Todoist-Gemini-Bridge
```

#### 2. Setup Virtual Environment & Install Dependencies
```bash
python -m venv venv

# On Windows (PowerShell):
.\venv\Scripts\activate

# On macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
```

#### 3. Configure API Credentials
Copy `.env.example` to `.env` and configure your tokens:
```bash
cp .env.example .env
```
Inside `.env`:
```env
TODOIST_API_TOKEN=your_todoist_api_token_here
WEBHOOK_SECRET_TOKEN=supersecret
```
> **Tip:** You can obtain your personal Todoist API token from [Todoist Settings > Developer](https://todoist.com/app/settings/integrations/developer).

### 🛠️ Usage Methods

#### Method 1: Direct CLI (No Server Required)
```bash
# From a JSON file
python main.py --file tasks_sample.json

# Direct JSON string
python main.py --json '[{"content": "Read book", "due_string": "today", "priority": 2}]'

# Interactive input (paste JSON and press Ctrl+Z / Enter on Windows, Ctrl+D on Unix)
python main.py
```

#### Method 2: FastAPI Webhook Service (`app.py`)
Start the background server:
```bash
uvicorn app:app --reload --port 8000
```
Interactive Swagger API docs will be available at `http://127.0.0.1:8000/docs`.

**Example cURL Request:**
```bash
curl -X POST "http://127.0.0.1:8000/tasks" \
  -H "Content-Type: application/json" \
  -H "X-Bridge-Token: supersecret" \
  -d '[
    {
      "content": "Review Pull Requests",
      "project_name": "Inbox",
      "due_string": "tomorrow at 10:00",
      "priority": 3
    }
  ]'
```

#### Method 3: Dispatcher Client (`send_to_bridge.py`)
Transmit payloads to your running FastAPI server via CLI:
```bash
# Send tasks from file to webhook
python send_to_bridge.py --file tasks_sample.json

# Custom server URL / token override
python send_to_bridge.py --file tasks_sample.json --url http://127.0.0.1:8000/tasks --token supersecret
```

#### Method 4: Gemini Function Calling
Use [gemini_tool_schema.json](gemini_tool_schema.json) directly in your Google Generative AI / Vertex AI Python SDK setup to let Gemini generate native structured task calls.

## 🇹🇷 Türkçe

Yapay zeka modellerinden (Gemini, ChatGPT, Claude vb.) veya otomasyon araçlarından (n8n, Make, özel Webhook'lar) üretilen yapılandırılmış JSON görev çıktılarını Todoist API'si üzerinden tek seferde, doğru projelere ve tarihlere otomatik eşleyerek ekleyen Python köprüsü.

### 🌟 Özellikler

- **Pydantic ile Şema Doğrulama:** Tekil veya toplu görev verilerinin tiplerini ve şemalarını sıkı bir şekilde doğrular.
- **Markdown & JSON Ayıklama:** LLM çıktılarındaki markdown formatlı kod bloklarını (````json ... ````) otomatik olarak temizler ve ayrıştırır.
- **Akıllı Proje Eşleme:** Görevdeki `project_name` değerini Todoist'teki projelerinizle otomatik eşleştirip `project_id` değerini bulur. Bulunamazsa görevi güvenle `Inbox`'a yönlendirir.
- **FastAPI Webhook Sunucusu (`app.py`):** CORS ve önceden paylaşılan gizli token (`X-Bridge-Token`) güvenliği içeren REST API uç noktaları.
- **İstemci Gönderici Script'i (`send_to_bridge.py`):** Webhook sunucunuza görev ileten bağımsız komut satırı aracı.
- **Doğrudan CLI Çalıştırıcısı (`main.py`):** Sunucu çalıştırmadan doğrudan Todoist'e görev ekleyen CLI script'i.
- **Gemini Fonksiyon Şeması (`gemini_tool_schema.json`):** Gemini Function Calling ile doğrudan kullanıma hazır araç şeması.
- **Güncel Todoist API v1 Desteği:** En güncel Todoist API (`https://api.todoist.com/api/v1`) uç noktalarıyla tam uyumludur.
- **Renkli Konsol Özeti ve Görev Linkleri:** Eklenen görevlerin doğrudan Todoist web linklerini ve özetini terminalde renkli tablo halinde gösterir.
